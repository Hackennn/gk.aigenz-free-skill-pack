# 🧋 The Bubble-Tea Prompt Cheat Sheet

> Vague order → random drink. Clear order → perfect drink.

## The 4 must-haves

| Slot | Ask yourself | Example |
|---|---|---|
| **WHO** | Who is it for? Who reads it? | "for my mum, turning 60" |
| **WHAT** | What exactly do I want back? | "a birthday message for a card" |
| **LENGTH** | How long? | "3 sentences" |
| **STYLE** | What tone or voice? | "warm, a bit funny" |

## 3 optional toppings

| Topping | When to add it | Example |
|---|---|---|
| **CONTEXT** | The AI needs background facts | "she loves gardening and always says she's 'only 39'" |
| **MUST / MUST NOT** | There are rules | "no emojis, don't mention her age directly" |
| **EXAMPLE** | You have a style you like | "like this: '…'" |

## Fill-in template (copy me)

```
Write [WHAT] for [WHO].
Make it [LENGTH], in a [STYLE] tone.
Context: [anything it needs to know].
Must: [rules]. Must not: [rules].
```

## Before → after

| ❌ Vague | ✅ Clear |
|---|---|
| "write a birthday message" | "Write a birthday message for my mum, who is turning 60. 3 sentences, warm and a bit funny, for a handwritten card." |
| "make a website" | "Make a one-page website for my home bakery in Penang. Customers order on WhatsApp. Sections: hero, 3 best sellers, how to order, contact. Soft pastel style, mobile first." |
| "fix my code" | "This error appears when I click Save: [paste error]. Find the cause, make the smallest fix, and show me how you checked it." |
| "summarize this" | "Summarize this article for a busy manager in 5 bullet points, under 80 words, plain English, with 1 action item at the end." |

## Bonus habits
- 🐟 **New task, new chat.** Long chats make AI forget the early stuff. Use `/handoff-summary`, then start fresh.
- 🗺️ **Big job? Plan first.** `/plan-first` before letting AI touch many files.
- 🔍 **Trust, but check.** AI can sound sure and still be wrong. Double-check facts, numbers and names.
