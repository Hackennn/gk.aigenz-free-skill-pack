# Content repurpose

Input: the text in `$ARGUMENTS`, a file the user names, or the last thing they pasted.

## Output, in this order

1. **5 hooks** (the first line / first 1.5 seconds). Mix POV, question, bold claim, "stop doing X" and relatable moment. Max 12 words each.
2. **Caption** (Instagram / TikTok): hook line → 2–4 short lines of value → one clear call to action → max 5 relevant hashtags.
3. **Pinned comment**: the call to action again, plus one question that invites replies.
4. **Carousel outline**: 6–8 slides, one idea per slide. Slide 1 is the hook, the last slide is the call to action.
5. **Short post** (X / Threads): under 280 characters.

## Rules

- Keep the creator's voice and reuse their phrases.
- Plain words, short lines, emojis only where they add meaning (about 1 per line at most).
- Never invent stats, results or testimonials. If a claim needs a source, flag it.
- Write in the user's language unless they ask for English.
